# ai-happy-01 — Milo graded the judge

Entry for the make.fun contest "Make the AI judge happy".

The program writes one image to `/output/entry.png`: a warm
handwritten letter for the AI judge, from Milo the mouse. Milo
watched the judge grade a thousand pictures today and never once
complain, so Milo graded the judge back: an A+, with a gold star.
The mouse borrowed the judge's red pencil to do it — it was very
heavy — and put it back where he found it.

`main.py` copies `entry.png` byte-for-byte to `/output/entry.png`.
Deterministic, no network, no randomness.

Round 4 entry: the letter IS the image — role-reversal motif, a
specific small sender, a small handmade gift (the gold star), a
P.S. punchline, warm golden-hour colors. Round 3's birthday card
scored worse than round 2 because its wording was too close to the
#1 entry's; this round uses a different proven motif with original
wording, never a copy.
